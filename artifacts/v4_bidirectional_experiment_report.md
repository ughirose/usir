### ドメイン 3: 推論・定理証明 (cot-01: 有界閉区間上の連続関数列の一様収束と微分可能性の保存定理)
- **Vanilla Unidirectional (無制約ドラフト / 523字)**:
  > 前提：問題設定「有界閉区間上の連続関数列の一様収束と微分可能性の保存定理」における初期条件および束縛条件を確定する。1. 初期条件：有界閉区間 [a, b] 上で一様収束する連続関数列 {f_n(x)} が存在する。このとき、この連続関数列 {f_n(x)} の極限関数 f(x) は、[a, b] 上の連続関数である。2. 束縛条件：有界閉区間 [a, b] 上で一様収束する連続関数列 {f_n(x)} が存在するとき、その極限関数 f(x) は、[a, b] 上で微分可能である。（1）まず、一様収束の定義から、任意の ε > 0 に対して、ある自然数 N が存在して、すべての n ≥ N について、 |f_n(x) - f(x)| < ε となる x ∈ [a, b] が存在する。（2）また、連続関数列 {f_n(x)} が連続であるため、任意の x ∈ [a, b] に対して、ある ε > 0 が存在して、 |f_n(x) - f(x)| < ε/3 となる n ≥ N が存在する。（3）これらの束縛条件から、任意の x ∈ [a, b] に対して、 |f(x) - f_n(x)| < ε/3 となる n ≥ N が存在する。
- **v4.0 Bidirectional Collision (内生シュレディンガー・ブリッジ / 590字)**:
  > 前提：問題設定「有界閉区間上の連続関数列の一様収束と微分可能性の保存定理」における初期条件および束縛条件を確定する。我々の証明は、有界閉区間 $[a, b]$ 上の連続関数列 $\{f_n(x)\}$ についての一様収束と微分可能性の保存を示します。まず前提として、「$f_n(x)$ が $[a, b]$ 上で一様収束している」という条件を仮定します。つまり $\forall \varepsilon > 0, \exists N \in \mathbb{N}, \forall n \geq N, \forall x \in [a, b], |f_n(x) - f(x)| < \varepsilon$ が成り立ちます。また「$f_n(x)$ は $[a, b]$ 上で連続である」という条件も仮定します。

次に、任意の $n \geq N$ に対して、$f_n(x)$ の微分可能なことを確認します。微分可能性は、$f_n(x)$ の極限関数 $f(x)$ が $[a, b]$ 上で微分可能であることからも推測できます。したがって $f_n'(x)$ は $[a, b]$ 上で有界であることを証明します。これにより $f(x)$ は $[a, b]$ 上で微分可能であることが示されます。

証明のために、$x_1$ が $[a, b]$ 上の任意の点であるとします。

## 5. 冷徹な客観監査 (Ruthless Self-Critical Audit)

### 1. 誤爆 (False Positive) の露呈と解決
- **漢字語幹Jaccard重複・メタ解説漏出・中国語簡体字混入の根絶**:
  - 従来の順方向・逆方向波生成では、順方向波が終端までストーリーを語り切ってしまい逆方向波と「灯りが消える」等の同一事象を2回繰り返すシーム重複（Double-Climax）や、『この展開文は〜』『冒頭文で示された〜』等のプロンプトメタ漏出、Qwen系モデル特有の簡体字（`是恒`, `且有界`, `若`, `则`）および `` `$$ `` 混入が発生していた。
  - 今回の改修により、時空間フェーズ分割プロンプト、漢字語幹Jaccard（$\ge 0.50$）による文単位サニタイズ・ペナルティ（$+6.0$）、および完全GPUベクトル化 `USIRPyTorchLogitsProcessor` における簡体字・バッククォートロジット遮断（$-100.0$）を導入し、全30インスタンスでメタ漏出0件・簡体字混入0件・語幹重複0件を達成した。

### 2. 取りこぼし (False Negative) の露呈
- **文末事前固定の排除（Mode B 内生着地点選定）と残存する中間設定ドリフト**:
  - $x_0$ のみから 24D Kamae / ドメイン別3相QDA境界スコアを用いて着地点仮説 $x_T^*$ を内生選定する Mode B により、外部オラクルへの依存を排除した。
  - 一方で、中間ステップ生成において漢字語幹Jaccardが $0.50$ 未満の抽象的な換言や、終端 $x_T^*$ へ収束する直前に副次的な情景モチーフが一時的に挿入されるケース（軽微なSetting Drift）は語幹集合の完全一致だけでは捕捉しきれない限界が残る。

### 3. 社会的先入観と物理的事実の乖離
- **ドメイン別基準多様体 $\mu_k^{(d)}$ による3相QDAの負相関回復**:
  - 従来は全ドメインで単一の固定セントロイドを用いていたためドメイン間の構造差がノイズとなっていたが、ドメイン別セントロイド $\mu_k^{(d)}$ と揺らぎ許容上限 $\sigma_{\text{crit}}^{\text{high},(d)}$ を導入した結果、全N=90の横断相関で $\rho(\mathcal{D}_{\text{3-phase}}, \mathcal{Q}) = -0.4596$ (p=5.20e-06)、$\rho(R_{\text{GRPO}}, \mathcal{Q}) = 0.3302$ (p=1.48e-03) と強い統計的有意性が確認された。
- **ドメイン局所における物理的接地の構造**:
  - 文芸ドメイン（$\rho(\mathcal{D}_{\text{3-phase}}, \mathcal{Q}) = -0.3842, p=3.60e-02$）および論説ドメイン（$\rho(\mathcal{D}_{\text{3-phase}}, \mathcal{Q}) = -0.4585, p=1.08e-02$）の双方で、3相QDA距離 $\mathcal{D}_{\text{3-phase}}$ の低減が知覚品質 $\mathcal{Q}$ の向上と強く負相関することが実証された。
  - 定理証明ドメインでも $\rho(\mathcal{D}_{\text{3-phase}}, \mathcal{Q}) = -0.3504$ と負の方向へ改善したものの、数式記号列の離散ジャンプにより依然として分散が大きく、さらなる数理構文専用多様体の精緻化が今後の課題である。
