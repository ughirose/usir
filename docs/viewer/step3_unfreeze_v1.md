## 3. 再結合の判定方法
1. 作品テキスト全体（場面の並びを連結したもの、`text.txt`）を、素朴なスタックで対応付ける（`「」` と `『』`。閉じ括弧は同種の最も内側の開きと対応し、その上に開いたものは暗黙に閉じる）。diagnose の「行頭の新しい「 による回復」は使わない。
2. unclosed 系の指摘: 開き括弧の対応する閉じ括弧が、開きのある場面の**次の場面**にある場合は、場面の切り分けによる見かけの指摘として出さない。
3. stray_closer の指摘: 対応する開き括弧が、閉じのある場面の**直前の場面**にある場合は出さない。
4. 上記以外（同じ場面の中の不対応、対応が見つからない、対応が 2 場面以上離れている）は確定として出す。
- 実装: `build_viewer.py` の `pair_brackets` / `rejoin_closed`。単体テスト `python/tests/test_viewer_rejoin.py`（3 件）。
