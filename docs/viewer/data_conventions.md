# 原稿データの置き方（規約・短版）

ロードマップ v2 ステップ1（2026-11-27）。ビューア（`scripts/viewer/build_viewer.py`）と診断を、原稿を壊さず・取り違えずに使うための置き方。

## 1. 1 場面 = 1 ファイル
- 1 つの場面を 1 つのテキストファイル（UTF-8、改行 LF）にする。ファイル名は `NNN_<場面の短い名>.txt`（NNN は 3 桁の通し番号、飛び番号を許す。例: `010_湯槽.txt`、間に挿入する時は `015_...`）。
- 作品フォルダ直下に場面ファイルを並べる。作品全体を 1 ファイルにまとめた版は、読み込み用に連結して生成する（手で編集しない）。
- 理由: 場面を差し替え・挿入・削除しても、他の場面の診断結果と場面注釈（キャッシュの鍵は場面本文のハッシュ）が無効にならない。変更した場面だけが再計算の対象になる。

## 2. 確定稿と下書きを分ける
```
<作品>/
  final/      確定稿の場面ファイル。診断・ビューアはここだけを読む
  drafts/     下書き・別案。診断・ビューアは読まない
  notes/      メモ（任意）
```
- 下書きを確定稿にする時は、`drafts/` から `final/` へファイルを移す（コピーではなく移動。同じ場面が二重に存在しない状態を保つ）。
- 確定稿の場面を書き換える前に、元のファイルを `drafts/` に残すかどうかを作者が決める。ツールは自動では移動も削除もしない。

## 3. 設定台帳（人物・場所・事実）
- 台帳に入るのは作者が登録した事実だけ。ビューアの「設定台帳」タブは、現時点では場面注釈から読み取った記録を表示する（作者登録とは区別して表示する旨を画面に明記している）。
- 台帳は原稿ファイルと別のファイルに置く（原稿フォルダの `ledger.json`）。原稿本文には書き込まない。

## 4. 公開テキストで試す時
- 公開テキスト（青空文庫など）だけを使う。未公開の原稿は、このリポジトリに置かない。
