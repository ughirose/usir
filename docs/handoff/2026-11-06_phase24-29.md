## 判断
1. **直喩の特徴量キャップは不採用**
   - 生成側の Goodhart 対策のために測定器を変えると、Table 1 系の結論（運動量 p の必要性）が変わる。
   - 生成の抑制は、ロジット減衰 `simile_decay` で行う。
   - キャップ版はブランチ `worktree-agent-ae5ea1a70587dd521`（`2962a7e`）に残してある。
2. **新機能はすべて既定オフ（kwarg で有効化）**
   - 対象: kv_share / batch_score / simile_decay / body_compound_protect / grace_close / genome_modes / mode_assign。
   - 理由: 過去の実験との再現性を保つため。
3. **quantile 割当は作家差を持たない**
   - モード比率は、構成上ほぼ固定（N/D/C = 0.56/0.25/0.19）になる。
   - LOWO は scaled 0.522（rule 0.543）、legacy 0.413（同値）。n=46、標準誤差 約 0.07 なので、差は有意でない。
   - 作家差は、モードごとの重心・精度に出る。
4. **genome_modes の G は、精度行列の qq ブロックをトレース正規化したもの（trace = 12）**
   - 単位行列と同じ全体スケールを保ち、作家の共分散の形だけを反映させるため。
   - quantile 版のゲノムでは、legacy の非対角成分は最大 0.006（ほぼ I）、scaled は 0.287。
