## 3. Judge（Phase 32）

- 方式: `LogitDebiasedPairwiseJudge`。
  - 両順序の logit 差 s_ab、s_ba から、選好 = (s_ab − s_ba)/2、位置バイアス = (s_ab + s_ba)/2 を求める。
  - 交差採点にした（Swallow が Qwen3 の出力を、Qwen3 が Swallow の出力を採点）。218.9 秒。
- 位置バイアス:
  - Swallow Judge は約 2.0 nats で、回答トークンに乗った確率質量は 0.621。
  - Qwen3 Judge は約 6.5 nats で、回答質量は 0.017。Qwen3 Judge は回答形式に従っておらず、信頼できない。
- 脱バイアス後の選好は |·| ≤ 0.6 で、符号は条件間で一貫しない。
  - 一貫したのは、Swallow Judge の「ctrl > 最下位条件」だけ（全文 3/4、段落 18/24）。
- 判定: ステアによる品質差は主張しない。
