# 引き継ぎ台帳 (docs/handoff/)

Antigravity と Claude Code の双方向の引き継ぎ置き場。

## ルール
- 作業開始時に、このフォルダの最新MD（ファイル名の日付が新しいもの）を読む。
- 作業の節目（機能完了・セッション終了・方針変更）に最新ファイルへ追記する。新しい日に始めるときは新規ファイルを作る。
- ファイル名: `YYYY-MM-DD_<topic>.md`
- 自動読み込み（`@import`）はしない。コンテキスト節約のため、必要時に読む。
- 実測値・テスト結果は、限界や未検証の点も含めて書く。

## 形式
```
# <題> (YYYY-MM-DD, 記入者: Antigravity | Claude Code)

## 決定事項
- 

## 未完了
- 

## 次の一手
- 
```
