- 特徴: P-1 Level 3a と同じ `extract_ortho24_kasane8`（32D）。場面分割は `split_work_into_scenes`（既定パラメータ）。

- Scheme 3 基準: 現代文（戦後）コーパス全場面で μ_r（各次元の平均）、σ_scene,r（各次元の標準偏差、ddof=1、下限 1e-6）。正規化 z = (x − μ_r) / σ_scene,r。

### 登録 3: R_xx（タスク B'）

- 報告: 作家ごとの値、中央値・IQR・最小・最大・平均。

- ヌル参照: 作家ラベルを場面間で置換（作家ごとの場面数を維持、2,000 回、seed 11）した R_xx の分布。ライン提案はヌル p95 と実測分布から行う（判定は Orion）。

### 登録 4: 摂動（タスク C'、場面単位。場面の元テキストに適用し、特徴抽出は摂動後テキストで行う）
RNG は `numpy.random.default_rng(20261117)` を場面順に 1 本使用（摂動種ごとに別 seed: 語尾 +0、読点 +1、感覚語 +2）。
1. 語尾単調化: 「。」の直前が平仮名で終わる文について、末尾の平仮名最大 3 字（文末の平仮名連続部分の末尾 3 字以内）を「である」に置換。適用率 100%（副: 50%）。
2. 読点崩壊: 「、」を各出現ごとに確率 0.5 で削除（副: 0.25 と 1.0）。
3. 感覚語欠落: `python/usir_py/extractor_24d.py` の `PHYSICAL_SENSE_INTERVALS`（リポジトリ内の物理感覚漢字区間）に含まれる文字を各出現ごとに確率 0.5 で削除（副: 0.25 と 1.0）。語彙リストの出所はこの定数のみ。
- 主解析の摂動強度は上記の主値。副値は用量反応の参考で、合否判定には使わない。

### 登録 5: 検出器と評価（タスク C'）
- スコア = 場面の z ベクトルの L2 ノルム（μ_r からの標準化距離、対角）。基準集合 = コーパス全無摂動場面。
- 動作点 = 無摂動スコアの 90 パーセンタイル（スコア ≥ 動作点で「異常」）。偽陽性率 = 無摂動場面で異常判定される割合。
- 主解析（定義どおり）: in-sample。基準と動作点を全無摂動場面から作り、全無摂動場面と全摂動場面で測る。この場合の偽陽性率は構成上ほぼ 10% になる（循環）。
- 副解析（保持評価）: 作品を単位とする 5 分割交差適合（seed 11）。学習側 4/5 の作品から μ・σ・動作点を作り、残り 1/5 の無摂動場面と摂動場面で AUC・偽陽性率を測る。保持評価の偽陽性率を合否の参考値として併記する。
- ROC-AUC: 摂動場面（正）vs 無摂動場面（負）。摂動 3 種を合算（見出し値）し、種別も報告。95% 信頼区間: 作品クラスタ・ブートストラップ（B=2,000、seed 7、作品を復元抽出）。
- 合格ライン（§25）: AUC ≥ 0.85 かつ 偽陽性率 ≤ 10%。見出し値は 3 種合算の AUC。種別の最小値も併記し、最終判定は Orion。
