### 2.2 粒度別（Granularity）微小推敲変動量と $2\sigma$ ゲート
既知 STYLE_POLISH 28件に対し、3つの粒度で変動量を実測した：

1. **`span_only`（編集スパン限定）**: 実際に編集された文のみを抽出・結合
2. **`local_context`（局所文脈窓）**: 編集文の前後に 1文ずつの文脈を含めて結合
3. **`whole_scene`（場面全体）**: 未変更文（20〜30文）を含む場面全体

|---|---|---|---|---|---|
| **`span_only`** | 6pole | **0.2121** | **4.57x** | 0 / 28 | 0.0% |
| | ortho28 | **2.8864** | **4.95x** | 0 / 28 | 0.0% |
| | ppm3d | **0.3326** | **3.91x** | **1 / 28** | **3.6%** |

> **物理的知見**: 編集スパンに限定することで、微小推敲シグナルは約 4〜5 倍に先鋭化される。しかし、隣接段落間の自然な語彙・構文揺らぎ（$\sigma_{\text{para}}$）自体が非常に大きいため、$2\sigma_{\text{para}}$ ゲート単独を絶対通過基準とする手法は、微小推敲の判定には依然として厳しすぎることが数値的に裏付けられた。

## 3. タスク2詳細：Gate 3a 現代文・Web小説前処理器と Tier C 規約

### 3.1 前処理器の仕様と実装
- **モジュール**: `python/usir_py/v5/modern_text_normalizer.py`
- **主要機能**:
  1. `normalize_modern_text`:
     - カクヨム・小説家になろう特有のルビ構文（`|親文字《ルビ》`、`親文字《ルビ》`、`親文字(ひらがな)`）を親文字へ非破壊縮約。注記 `（注）` や括弧笑い `（笑）` は除外対象外として安全に保護。
     - 三点リーダー（`…`, `......` $\to$ `……`）およびダッシュ（`―`, `—` $\to$ `――`）を標準組版ペアに統一。
     - 連続感嘆符・疑問符（`!?` $\to$ `！？`, `??` $\to$ `？？`）を全角正規化。
  2. `compute_punctuation_normalization_diff`:
     - 前後文字数デルタ、約物増減数、および会話文比率（`dialogue_ratio`）を算出。会話主体レイアウト（会話比率 50〜80%）や極小文入力でもゼロ除算を完全防止。
  3. `extract_tier_c_irreversible_profile`:
     - 著作権法30条の4に基づく情報解析用クリーンルーム抽出器。
     - 固有名詞・内容語を `■`（U+25A0）にマスクし、非可逆な統計値（`ortho_v2` 31D、文法骨格 PPM bits/token、閉クラス被覆率）のみを出力。
     - 関数の終了時に生テキスト変数およびトークン参照を `del` および `gc.collect()` で物理破棄。
- **検証テスト**: `python/tests/v5/test_modern_text_normalizer.py`（5件全パス）。出力辞書内に原文の部分文字列が一切漏洩しない「クリーンルーム不変条件」をアサーション確認。

  - Claude Code 側での CLI 実行やサンドボックス環境でのモジュール衝突が根本解消。

### 4.2 閉鎖系 4パターンの誤爆除外同期
Claude Code / Nishiki 側で検出された既知の誤検出パターンを `u6_guards.py` に完全同期：

1. **数詞イディオム除外**:
   - `一通り`、`一旦`、`一応`、`一緒`、`一層`、`一向`、`一斉`
   - これらが含まれる文（例: 「一通りの確認をした」）において、「一」が数詞 1 として誤抽出されるバグを完全遮断（`extract_numerals` $\to$ `[]`）。
2. **副詞的 `十分` 除外**:
   - 直後に助数詞・時間接尾語（`間`、`後`、`前`、`目`、`足らず`、`あまり` 等）を伴わない場合を副詞（充分の意）として扱い、数詞 10 から除外。
   - 例: 「十分に休んだ」 $\to$ `[]`（同義置換「充分に休んだ」で STYLE_POLISH 維持）。
   - 一方、「十分前に出発した」 $\to$ `[10]`（「三分前に出発した」`[3]` との比較で CONTENT_REWRITE を正しく検出）。
3. **否定副詞除外**:
   - `先ず` / `まず`: 「先ず、彼に挨拶した」において「ず」が助動詞否定として誤カウントされるバグをマスク除外（極性 0 を保証）。
4. **複合推量モダリティ・形容詞語幹除外**:
   - モダリティ: `違いない / ちがいない / かもしれない / かも知れない`（およびその過去形・活用形）の「ない」を肯定的な推量として保護（極性 0）。
   - 形容詞語幹: （`少 / 切 / 危 / 汚 / 儚`）＋`ない`（少ない、切ない、危ない、汚い、儚い）を状態形容詞として保護（極性 0）。

## 5. 死角・限界・誤爆の客観開示（Ruthless Self-Critical Audit）

行動規範（全プロジェクト共通規律）に基づき、本実測の死角・限界を率直に開示する：

1. **死角1（コーパス全体平均への回帰との区別不能性）**:
   - v4 D4 で定められた「目標作家重心方向への余弦 vs コーパス全体平均方向への余弦」の検証において、全特徴空間で Wilcoxon 検定の有意水準 0.05 をクリアできなかった（6pole $p=0.0854$, ortho28 $p=0.2124$, ppm3d $p=0.4955$）。
   - これは、人手による文体推敲（口語調「のだ」$\to$ 擬古文調「のであった」、接続詞「しかし」$\to$「ところが」等）が、**特定作家の個性に接近しているのではなく、近代文学コーパス全体の標準的文語規範（平均）に向かって移動しているに過ぎない**という冷徹な事実を示している。「この推敲によって特定作家らしさが高まった」と主張することは統計的に正当化されない。
2. **死角2（段落ノイズ床 $\sigma_{\text{para}}$ に対する推敲差分の微小性）**:
   - 編集スパンに限定することで変動量は約 4.5倍に増幅されたものの、段落ノイズ床（隣接段落間の自然な揺らぎ）が $\sigma_{\text{para}} \approx 4.0$（ortho28）と巨大であるため、$2\sigma_{\text{para}}$ ゲートの通過率は依然として 0%（PPM でわずか 1/28件 3.6%）にとどまった。
   - 自然な段落間の揺らぎ（Content Variance）と文体推敲（Style Polish）を絶対ノルム（ゲート）だけで分離することは不可能であり、方向性（余弦アライメント）との複合判定が不可欠である。
3. **死角3（短文における漢字 Jaccard の過敏性）**:
   - `一万二千円` $\to$ `12000円` のように、漢字数詞が算用数字に置換された場合、短文（10文字程度）では漢字集合の Jaccard 係数が 0.55 を下回り、表層乖離（`SURFACE_DIVERGENCE`）として誤却下されるリスクがある。文脈長に応じた動的 Jaccard 補正が今後の課題である。
