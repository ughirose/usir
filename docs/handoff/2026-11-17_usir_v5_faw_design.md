## B. 連続補助指標の設計

共通方針（S_haz 前例の踏襲）:
- 踏襲: 離散指標は legacy として残し併走。無重み版を正本、感度対照は別パラメータで併記。退化入力は (ii-a) 型（入力の欠如のみ `None`）。入力は決定論・閉クラス特徴のみ。Tier 1（凍結注釈へ直接適用）／Tier 2（v5.1 以降の注釈器更新層）の 2 層。
- 変更: S_haz は単一指標だが、本件は 4D×2 で欠陥の種類が次元ごとに異なる。規則は次元別に書く。
- (ii-a)/(ii-g) の定義は B-22 報告（`stage/b22-kamae-haz:docs/handoff/2026-11-15_usir_v5_stage_b22_report.md` §1・§4.2）で確認した。(ii-a) は入力の欠如（作品が空・非連続・曝露ゼロ）に対してのみ `None`。(ii-g) は結果が 0 の作品を除外する形で、生存者選択バイアス（ρ=+0.1977〜+0.3033）を生むため禁止。本設計は「信号が 0 の作品」を除外せず 0 として保持する。

### B.1 Awase：候補の軸（独立に設定）
1. クリップ位置: 場面内 ReLU／符号付き生値を作品単位まで保持。
2. 入力の連続性: 量子化後の整数（Tier 1）／量子化前の生値（Tier 2、注釈スキーマへの追加が必要）。
3. 結合の形: 場面ごとの積の平均／場面間の共分散。
4. 位置依存: 先頭末尾差／位置への OLS 傾き。

#### 候補
- **AW-1（推奨、Tier 1）符号付き対位平均**
  - `C_irony = mean_t(−V_F(t)·V_f(t))`、値域 [−1, 1]。`C_det = mean_t(|V_F(t)|·(A_F(t)−A_f(t)))`、値域 [−2, 2]（旧 detachment の ReLU を外したもの）。
  - 退化: 場面数 0 のみ `None`。1 場面でも定義できる（平均）。既定値の代入はしない。
  - 旧指標との関係: `irony_mean = mean(max(0, s_t))`、`C_irony = mean(s_t)` で `s_t = −V_F V_f`。差は同符号場面（13.3pt）の寄与。`irony_active` は AW-1 では不要（二値集約のため併走させない、legacy のみ）。
  - 計算量 O(T)。
  - 効果の限界: 入力側の 0（76.5pt）は残る。作品単位のゼロ率は 16.04%→13.21%（AOZORA106）、異なる値の数は 61→77。
- **AW-2（Tier 2）生値版**: `V` を量子化前の `val_e_raw`／`val_s_raw`（`aozora_scene_splitter.py:732, 742`）に置換した符号付き平均。注釈器のスキーマ拡張（`deny_unknown_fields` のため v5.1 以降）が必要。作品単位ゼロ率 5.66%（AOZORA106）、異なる値 98/106。連続性は最大だが、スキーマ変更と再注釈を伴うため Tier 2 とする。
- **AW-3（参考・非推奨）場面間共分散** `−cov_t(V_F, V_f)`: 分母なし、常に定義可。`C_irony = −cov − μ_F·μ_f` の関係（定義式から導出）があり、AW-1 と線形従属に近い。独立な情報にならないため併走の対象にしない。
- **AW-4（傾き、`irony_grad` の後継）**: `G = OLS slope(s_t ~ 正規化位置 x_t ∈ [−0.5, 0.5])`。T≥3 で定義、T<3 は `None`。場面数による分岐を持たない。パイロットでは作品分割の再現性が不安定（§C.3）。
- 不採用: 平滑 ReLU（softplus 等）。入力 0 が 76.5% を占めるため、ゼロ率を下げない。

### B.2 Nagare：候補の軸
1. 閾値の扱い: ハード閾値＋run 本数（現行）／滑らかなカーネル／分位統計。
2. 集約: 場面平均／前半後半比／OLS 傾き。
3. 基準: 絶対スケール（rad）／作品内分位。作品内分位は作品間比較を失うため不採用。

#### 候補
- **NG-0（変更なし）**: `phi_zeami`、`mood_speed_mean`。張り付きなし、既に連続。退化契約のみ見直す（空入力は `None`、0.5/0.45 の代入を廃止）。
- **NG-1（推奨）滑らかな静止質量** `S_still = mean_t exp(−(J_t/θ)²)`、`J_t = max(event速度_t, mood速度_t)`、`θ = 0.25`（現行 Python の固定閾値）。感度対照として θ∈{0.20, 0.35} を別パラメータ。値域 (0, 1]、遷移数 0 のとき `None`。旧 still（両速度<θ）の連続化（`max<θ` の滑らかな近似）。ゼロ率 0%（パイロット）。ハードなヒンジ版 `max(0, 1−J/θ)` は群単位ゼロ率が 0.74（POSTWAR）に残り不採用。
- **NG-2（`speed_ratio` の後継）速度傾き**: mood 速度の位置に対する OLS 傾き。遷移数≥3 で定義、<3 は `None`。+1e-4 を持たず、半分割の境界を持たない。
- **NG-3（不採用）速度の lag-1 自己相関**: パイロットで 2 コホートの符号が逆（§C.3）。
- **NG-4（参考）joint 速度の p10**: 張り付かないが再現性の手掛かりなし（パイロット r≈0.04〜0.08）。

### B.3 退化ケース契約（共通、(ii-a) 型）
1. `None` を返す条件は入力の欠如のみ: 場面 0、遷移不足（傾きは遷移<3、静止質量は遷移 0）。
2. 信号が 0 の作品は 0 として保持し、除外しない（(ii-g) 禁止）。
3. 既定値（0.1／0.12／0.45／0.5／1.0）の代入を禁止。欠測は `None`（Rust `Option::None`、Python `None`）。集計側は除外件数を全件計上する。
4. 分母に ε を足して値を作る定義を使わない（`speed_ratio` の +1e-4 を廃止）。傾きの分母は位置のみで決まる（T≥3 で非 0）。
5. 場面数による定義の分岐を連続指標に持ち込まない。最小場面数未満は `None`。

### B.4 Scheme 3 レジスター基準との整合
- 場面単位の量（AW-1 の `s_t`、`(|V_F|(A_F−A_f))_t`、NG-1 の `exp(−(J_t/θ)²)`）は P-2c と同形式（場面単位の μ_r, σ_scene,r）で z 化できる。作品単位の平均・傾きは場面値の線形集約。
- Awase の場面値は構造的に 0 の質量が大きい。σ_scene,r の下限（P-2c の `SIGMA_FLOOR`）の適用を設計書 C で確認項目とする。
- 遷移の量（Nagare）は場面 t→t+1 に割り当てる。場面数 T に対し遷移数は T−1。

### B.5 Tier 構成
- Tier 1（凍結注釈へ直接適用、再注釈なし）: AW-1、AW-4、NG-0、NG-1、NG-2。既存の凍結成果物（216 正本、Gate 3a/3b、実推敲ペア v1.1）と後方互換。
- Tier 2（v5.1 以降）: AW-2（注釈器が量子化前の生値を出力）。

## C. 計測計画（事前登録案）

### C.1 前提とデータ分離
- 本設計の探索計測（§A、§C.3 のパイロット）は AOZORA106 と POSTWAR を用いた。確認検証にはこの 2 コホートを使えない。確認用に、設計に使っていない作品群を事前に固定する。候補: `data/aozora_cache` の `p2cA2`（84 件）、`p2cE`（67 件）。これらが P-2c の Level 3b／エッセイ試行／重心計算で既に使われているかは、本ステージで未確認（未検証）。使用状況を確認してから指定する。
- 実装後に行う検証の単位は作家。P-2c の登録 B（場面数降順・作品 ID 昇順の貪欲 2 群分割、場面数が少ない群へ割当、同数は A）を踏襲する。

### C.2 検証項目（実装後）
1. 再現性 R_xx: 作品分割の 2 群で各指標（連続候補／旧指標）を計算し、作家をまたいだ Pearson r と Spearman ρ を算出する（P-2c は 32D の cosine。スカラー指標のため作家間相関を用いる）。作家数の下限（≥2 作品の作家数）を登録する。
2. ノイズ床: P-2c の 216 正本ノイズ床（F-22）との関係を、同一手順で各指標の摂動応答の SD として比較する。
3. 摂動感度: P-2 の摂動 3 種（ending／comma／sensory）への応答量 `|Δ指標|/σ_scene,r` を旧指標と並べて報告する。連続指標が摂動に敏感すぎる場合（応答が旧指標の 2 倍超など）は閾値を事前登録して判定する（閾値値は Orion）。
4. 旧指標との関係: Spearman ρ(新, 旧)。ρ>0.95 は情報の追加なしとして記録する（閾値は提案）。独立性の維持は nHSIC（B-22 の nHSIC 値 0.1124 と同定義）で比較する。HSIC の取り扱いは Orion／Gemini の論点（§D.3）。
5. 退化・欠測の全数センサス: `None` の件数を作品単位で全件計上する。
6. 場面数依存: 作品の先頭切り詰め（K=20→200 に準じる）での指標ドリフト。

- 「Awase の低再現性が張り付きの帰結か」は、この計測では切り分けられていない（未検証）。

### C.4 合格ライン（提案、確定は Orion）
根拠が計測から得られていないため、数値の提案は置かない。登録すべき形だけを示す: (a) 確認データでの旧指標に対する R_xx の差の 95% 信頼区間（作家単位ブートストラップ）の下限が 0 を超えること、(b) 欠測率が旧指標のデフォルト代入率を超えないこと、(c) 摂動応答比の上限。(a) のブートストラップのシード・反復数は実装前に固定する。
