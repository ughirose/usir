# Phase 23 報告：句読点・リズム・改行・造語・モデル選定（2026-11-06）

対象コミット: `e3ec79c`（リズム機構）、`f6db574`（内容語反復の段落スコープ）、`f04ad51`（n-gram 照合の段落スコープ）。
生データ: `docs/handoff/v8/p23_*.json`、`p23r_*.json`、`p23s_*.json`、`p23_bakeoff_{a,b}.json`。

## 1. ユーザーの指摘への回答（測定値つき）

### 1.1 「終盤に向かって句読点が不自然に頻出する」
- 測定では、読点「、」は終盤に向かって増えていなかった。増えていたのは句点「。」で、Climax 段落の文が最も短かった。
- 原因は `_rhythm_params` にあった。毎段落 `n_sent % 3` で「短・中・長」を機械的に回し、さらに CV 下限ポテンシャルで文長の揺れを強制していた。
  - 短モードの設定は、「。」+8、「、」-12、上限 13 トークン。
  - Climax 段落では Shock 側の短文化が重なっていた。
- Phase 21 の出力と青空文庫の作家帯を比べた結果は次のとおり。

  | 対象 | 平均文長 | 読点/100字 |
  |---|---|---|
  | Phase 21（3B / 7B） | 13〜31 字 | 4〜10 |
  | 青空文庫の作家帯 | 31〜48 字（谷崎は 77） | 2.4〜6.5 |

### 1.2 「ためないことも必要」
- `rhythm_profile="steady"` を追加した（文長 16〜90 字、読点は 1 文 3 個まで、周期なし）。Climax 段落だけ `pulse` にする。
- `cv_ceil`（文長 CV の上限）を追加し、揺らしすぎを抑えた。
- 結果（8B）: new_ctrl の平均文長は 27〜37 字で、min（制御なし）の 25〜37 字と同程度だった。周期的に文を刻む挙動は消えた。
- 未解決: new_B の CV_L は 0.43〜0.62 と高めだった。ゲノムでステアすると文長の揺れが増える。

### 1.3 「改行がない」
- `text_format.format_novel` を追加した。段落間を空行にし、120 字目安で意味段に区切り、「」の会話は独立行にする。全実行の `formatted_text` に入っている。
- 未解決: Qwen2.5-3B は半角の `"…"` で会話を書き、閉じ忘れも多い。`format_novel` は「」しか認識しないため、3B では会話の途中で段落が切れる。

### 1.4 「1.5B / 3B は意味が通らないことが多い。元々の日本語性能の問題か」
- 両方が原因。比重はパイプライン側の方が大きかった。
- 制御なしの比較（`p23_bakeoff_a`）では、Qwen2.5-3B と TinySwallow-1.5B も筋の通った短文を書いた。Phase 21 での破綻の主因は、制約の積み重ねだった（造語の誘発、短文の強制、語の禁止）。
- ただし 3B は制御なしでも不安定だった。場面にそぐわない語（「クラクション音」）、文の反復、会話の書式が崩れる。基礎性能の限界は確かにある。
- 3B は禁止された語の言い換えが苦手。同じ制御をかけたとき、8B より崩れが大きかった。例: p23r_q25_3b の new_ctrl で「懐中時の計」「懐中時鐘」「懐中時鍾」「老職人的顔」。
- 結論: USIR の制御を前提にするなら 8B 級を使う。3B 以下で使うなら、制御を弱める必要がある。

### 1.5 「Qwen2.5 が最適か。Qwen3 系や Bonsai は」
- Qwen2.5 は最適ではない。制御なしの 11 モデル比較と、制御ありの 8B 比較をもとにした判断は次のとおり。

| モデル | 評価 |
|---|---|
| Qwen3-Swallow-8B-RL-v0.2 | 第一候補。平均文長 31〜37 字で、青空文庫の作家帯に入った唯一のモデル。今回の造語は 1 件（下記）。難点は「まるで〜」の直喩の多用（1 本あたり 9〜13 回）。 |
| Qwen3-8B | 第二候補。論理的で読みやすい。文はやや短め（25〜32 字）。 |
| Qwen3.5-9B | 制御なしで最も文学的だった（CV 約 0.27）。ImageTextToText 構造のため、制御ありの実行はまだしていない。 |
| Qwen2.5-7B | 使えるが、造語が最も多かった（修正前）。 |
| Qwen2.5-3B、TinySwallow-1.5B | 制御なしなら可。制御ありには不向き。 |
| Bonsai-8B-unpacked | 不適。反復が多く（distinct bigram 0.18）、英語が混入する（"howl"）。 |
| sarashina2.2-3B | 不適。途中で英語に切り替わる。 |
| llm-jp-4-8b | "final" などテンプレート由来のトークンが漏れる。 |

## 2. 造語の原因と修正

| 段階 | 原因 | 修正 | 結果 |
|---|---|---|---|
| ① | `ContentRepLogits` がプロンプトのテーマ語・役割語まで反復とみなして罰していた | `cr_paragraph_scope`（`f6db574`） | 「青年人」は消えた。「懐中時鐘」「懐中時針」は残った。 |
| ② | `ContextNgramBan` がプロンプト全体を n-gram 照合し、「懐中時」の後の「計」を -4（soft 4-gram）で抑えていた | `ngram_paragraph_scope`（`f04ad51`） | new_* の「懐中時計」は 0 回から各 1 回になった。 |
| ③（残存） | 前段落で使った語を、段落間の n-gram 照合（`hist_map`）が 2 回目以降に抑えている可能性が高い（未検証） | 未修正 | 8 本中 3 本で造語が 1 件ずつ出た（「懐中時針」「懐中時刻」）。 |

- 再実行（p23s、A100）の結果は次のとおり。
  - Qwen3-8B: 「懐中時計」は 4 本とも 1 回で、造語は 1 件。
  - Swallow-8B: 「懐中時計」は 4 本とも 1 回で、造語は 2 件。
- ③の修正案: テーマ語・役割語の漢字列（「懐中時計」「老職人」など）を保護語にする。行末がその語の途中で止まっているときは、続きのトークンを n-gram 禁止の対象から外す。

## 3. 構想全体の内省（指示外の点検）

1. **代理指標の Goodhart 化。** CV_L 下限、統計ゲート、ΔLL はすべて Phase 21 で合格した。それでも本文には造語、反復の崩壊、連体修飾の途中での文の分断があった。指標を下限で強制すると、本文は悪くなる。今後は、目標作家の分布から作った帯（上下限）として扱い、強制ではなく監視に使うべき。
2. **LLM Judge の飽和。** 7B の自己採点は全条件で 93.8 だった。条件間の差が判別できない。今後は、ペア比較（A/B のどちらが良いか）か人手評価が必要。
3. **ゲノムは重心しか使っていない。** `style_genome` のステアはモード重心の平均だけを使い、精度行列を使っていない。そのため α=0.75 と legacy の出力は完全に一致した。`momentum_from_summary` の条件付き運動量も、生成経路にはつながっていない。
4. **ゲノムでステアした効果は確認できていない。** 確認できたのは ΔLL がゲノム B 側に動いたことだけ（5 組中 5 組）。A 側には近づかなかった。今回の p23 でも、new_B の ΔLL は new_ctrl より小さい組が多いが、一貫しない（Swallow s3: 8.15 → 5.09、s42: 7.90 → 9.40）。
5. **制約の総量。** 小さいモデルほど、制約で質が下がる量が利益を上回る。抑制系の制御（禁止、ペナルティ）は、モデル規模に応じて弱めるか、既定でオフにする方がよい。
6. **アブレーションの不足。** 「USIR 制御あり vs なし」の差は、今回の min / new_ctrl の比較が初めて。読んだ印象では、8B の new_ctrl は min と同等以上（会話の挿入、段落構成）。ただし評価者 1 名の主観で、統計的な主張はできない。

## 4. 残る欠陥（今回の出力を読んで見つけたもの）
- 段落の境目で文が切れる（Qwen3 p23s new_ctrl_s42: 「時計は、また、」で段落が終わり、次段落が「止まったままのままだった」で始まる）。
- Swallow の直喩の多用（「まるで」が 1 本あたり 9〜13 回）。直喩は Group IV の Shock 指標なので、制御がこれを促している可能性がある。未検証。
- 連体修飾の途中での分断の疑いは、min の 33〜46 件に対し、new_* で 28〜39 件。減ってはいるが残っている。件数は文字規則による推定で、正解ラベルはない。
