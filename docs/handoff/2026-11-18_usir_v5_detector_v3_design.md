## 1. 評価シナリオ（事前登録の解釈固定）
作品内 LOO 正規化は、評価対象の場面の「同一作品の他場面」を基準にする。基準にする他場面の版を次のとおり固定する。
- **主（A）: 単一場面改変シナリオ**。陽性＝場面 i のみ摂動、陰性＝場面 i の無摂動。どちらも基準は同一作品の**無摂動の他場面**。
- **副（B'）: 作品全体改変シナリオ**（報告のみ、ヘッドラインに使わない）。陽性の基準は、同一摂動を適用した同一作品の他場面。陰性は A と同じ。作品全体が同方向にずれると作品内基準も動くため、正規化の効果は A より小さくなる見込み（推測）。
- 評価コーパスの全場面に摂動を適用した P-2c の陽性データは、A では「場面 i 以外は原文」として扱うため、陽性の基準には `X`（無摂動）の他場面を使う。

空白類（`\s` と全角空白）を除いた場面テキストを t2 とする。q1〜q3 は P-2c と同一定義（元テキスト t 上）。

| q3 | 文末多様性 = 異なる文末3文字数 / 文数（P-2c の `surface`） | 減少 |
| LS | 平均文長 = 文の総文字数 / 文数（t2、文は `[^。！？]+[。！？]+[」』）)]*`、文なしなら len(t2)） | — |
| DR | 会話比率 = 会話スパンの文字数 / len(t2)。会話スパン = `「[^」]*」` または `『[^』]*』` | — |
| S1a | 期待読点残差 = q1 − q̂1(LS, DR)。q̂1 は学習 fold の無摂動場面で `q1 ~ 1 + log(LS) + DR` を OLS 回帰 | 減少 |

## 3. 作品内 LOO 経験ベイズ正規化
学習 fold の無摂動場面から、信号 j ごとに次を求める（学習 fold の場面のみ使用）。
- μ_G,j = 全学習場面の平均。
- σ²_W,j = 作品ごとの不偏分散（ddof=1）を場面数 −1 で重み付けしたプール分散（作品内プール分散）。

場面 i（作品 w）の信号値 x_i（陰性は無摂動値、陽性は摂動後値）を、同一作品の基準場面集合 R_i で正規化する。A では R_i = {同一作品の他の無摂動場面 j≠i}。k = |R_i|、m = R_i の平均、s² = R_i の不偏分散（k≥2、そうでなければ 0）、m0 = 8。

- μ_i = (k·m + m0·μ_G) / (k + m0)
- σ²_i = ((k−1)₊·s² + m0·σ²_W) / ((k−1)₊ + m0)  （(k−1)₊ = max(k−1, 0)）
- z_ij = sgn_j · (x_i − μ_i) / max(σ_i, 1e-6)

m0=8 は仕様固定値。k=0 のとき μ_i=μ_G、σ_i=σ_W（作品内プール）となる。

## 4. 分位校正と集約
- 学習 fold の各無摂動場面に対し、その場面の作品内 LOO 正規化（学習作品内の他場面を基準）で z_ij を得る。これを信号 j の校正分布 F_j（経験分布）とする。
- 片側分位スコア: u_ij = −log p_ij、p_ij = (1 + #{F_j の値 ≥ z_ij}) / (N_train + 1)。
- 集約: score_i = max_j u_ij。
- 動作点: OP-A = 学習 fold の無摂動場面の score の 90 パーセンタイル（学習 fold の陰性は校正に使ったデータ内の値）。OP-B = 学習作品内の入れ子 5 分割（作品単位、seed = 11 + fold、P-2c と同一）で、内側の保持陰性 score の 90 パーセンタイル。内側の各分割でも、校正・μ_G・σ_W・回帰係数は内側学習作品のみから求める。
- 合格評価の主構成は OP-B・全体。ROC-AUC は 3 摂動の陽性をプールして陰性と比較（P-2c と同一）、摂動別も報告。

## 5. 評価プロトコル（P-2c と同一）
- 作品単位 5 分割交差適合（`workset_folds(all_works, 11)`）。全体／P-2b 既存／新規／外部評価（P-2b 既存を学習、新規で評価）の 4 分割。
- 摂動は P-2c と同一（`scripts/p2b/p2b_analysis.py::perturb`、コホート単位・マニフェスト順）。再生成した q1〜q3 が `data/p2c_scene_profiles.npz` の `Q`・`Q_*`・`Qd_*` と完全一致することを入力量生成時に検証する。
- 95% CI: 作品単位クラスタ・ブートストラップ（B=2000、seed 7）。
- 用量反応（副解析）: P-2c と同一条件（ending@0.5、comma@0.25／1.0、sensory@0.25／1.0）。
- 外部評価: P-2b 既存コホートの全作品で学習（入れ子 OP-B も内部）、新規コホートで評価。評価場面の LOO 基準は評価作品内の他の無摂動場面のみ。

## 6. 漏洩防止の仕様
1. μ_G、σ_W、回帰係数、校正分布 F_j、動作点の閾値は学習 fold の作品のみで計算する。評価 fold の場面・作品は参照しない。
2. 評価場面の LOO 基準は同一作品（同一 fold に属する。fold は作品単位）の他場面のみ。他 fold の作品は参照しない。
3. 評価場面自身（i）は基準から除外する（LOO）。陽性場面の基準にも摂動後の自分自身は入らない。
4. 評価場面のラベル（陽性・陰性）は正規化・校正に使わない。作品内基準は無摂動テキストのみ（A）。
5. 実装でテスト: 評価 fold の場面値を任意に書き換えても、他の場面のスコアが LOO 範囲外で変わらないこと、学習 fold の値を変えた場合のみ校正が変わること（単体テスト）。
