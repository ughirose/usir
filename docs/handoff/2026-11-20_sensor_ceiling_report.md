## 4. 強いモデルでも当たらなかった項目と、本文に照らした理由

### 4.1 事実: 意味は同じだが照合規則で不一致になるもの（6 対）
照合規則は「同じ述語かつ object の部分一致、または bigram の重なり 0.5 以上」。言い換えは通らない。
- 001798 場面3: ゴール HOOK_OPENED「家の二重契約の誤解」／注釈 HOOK_OPENED「不破数馬との売買をめぐる誤解」。本文は野呂と僕が同じ家を不破から契約したと分かる場面で、同じ出来事を指す。共通語が「誤解」だけで不一致。
- 001798 場面2: ゴール noro LEARNED「不破が出発したこと」／注釈 noro LEARNED「不破が兵庫に立った」（本文「不破さんは昨日兵庫県に立ちましたよ」）。
- 001801 場面1: ゴール HOOK_OPENED「女の自殺の意図」／注釈 HOOK_OPENED「女は死ぬのか」（本文「あなたは、自殺するつもりですか？」）。
- 000035 場面2: ゴール yozo ACQUIRED「女給の恩」／注釈「大カフエの女給から受けた恩」。「女給の恩」が連続部分文字列にならず、bigram の重なりが 1/3。
- 001875 場面2: ゴール「兵六が進君の生活費を渡さない」／注釈「進君の預けた金が兵六から払われない」。
- 000050 場面2: ゴール「手毬と旅の書生をめぐる出来事」／注釈「旅の書生が川で手毬を拾った奇妙な出来事」。
HOOK_OPENED は自由記述の言い換えが多く、この規則では一致しにくい。強いモデルでも R の上限が下がる原因。

### 4.2 事実: 向き・述語・粒度の違い
- 001801 場面1: ゴール shinichi LOST「父」。本文「死にました。去年」。注釈は同じ出来事を onna LEARNED「慎一の父は去年死んだ」と書いた。同じ出来事を失った側（LOST）で書くか知った側（LEARNED）で書くかが課題定義で決まっていない。001798 場面1 も同様で、ゴールは fuwa ACQUIRED「二千円」、注釈は boku LOST「二千円」。
- 001383 場面5: ゴール hagiwara MOVED_TO「信一の家」／注釈 MOVED_TO「中二階の十畳の間」。同じ移動を、場所の粒度を変えて書いた。
- 000035 場面6: ゴール yozo STATE_CHANGED「酔って大胆になる」（本文「酔って大胆になっているからでもありましたが」）。注釈は同じ場面の主題をツネ子への恐れとして書き、この句を落とした。注釈側の取りこぼし。
- 001798 場面0: 注釈の boku LOST「四万円」・ACQUIRED「間借り」・LEARNED「酒豪」の 3 件がすべて FP。ゴールにはこの場面の事実が 1 件しかない。「更新に含めない」の基準（会話や反復動作を除く）の運用が、ゴールのほうが狭い。同様の FP が 52 件ある。

### 4.3 特性: ゴールが人物の安定した性格を全場面に付ける
- 001798 boku: ゴールは場面0〜2 すべてで秩序 +1（[0,1,0,0,0,0]）。注釈は場面3 の「ちゃんと権利金を払い、きちんと賃貸借の契約をした」にだけ +1 を付け、場面0〜2 は 0。場面0 の「かんたんな契約書を作成し、四万円を手交し」、場面1 の「間代前納の形式ならそれでもいい」も根拠にはなり得るが、場面単位の判断では弱いと見て 0 にした。同じ種類の外れが多い（001383 の shinichi は 6 場面中 5 場面が同一の [0,−1,0,−1,1,0]、senkichi・hagiwara の宿命 −1、000081 の giovanni の自由意志 +1 など）。ゴールの特性値は、場面内の言動というより人物像の判断に見える。
- 001383 shinichi: ゴールは [0,−1,0,−1,1,0] を 5 場面で固定。注釈は秩序 −1 を付けていない。本文は信一が仙吉を縛り、額に炭を塗るごっこ遊び（「貴様は罪人だから額に入墨をしてやる」）。遊戯の暴力を「逸脱」とみなすかが軸の定義（[1] 反逆・逸脱／秩序）から決まらない。
- 001798 fuwa: ゴール [0,−1,0,−1,0,0]（秩序 −1・利己 −1）。注釈は [0,0,−1,0,0,0]（世俗・金銭 −1）。同じ「金を借りる」行為を、軸 [2]（世俗・金銭・打算）と [3]（利己・支配）のどちらに置くか。軸の定義が重なっていて、人によって割れる。
- 000035 yozo の利己・献身（人物単位の逆符号 1 件）: ゴールは軸 [3] を −1（場面2）とし、場面1 は 0。注釈は場面1 で +1（本文「れいの受け身の奉仕の精神を発揮して」）、場面2 では同じ「奉仕」を軸 [4] の −1（打算）に置いて軸 [3] は 0。人物単位に集約すると、ゴール −1 に対し注釈 +1。本文の字面は献身側、内心は「早くこのひと、帰らねえかなあ」「いよいよその醜い、いやな女に奉仕をして」で打算側。字面と動機のどちらを採るか、奉仕を軸 [3] と [4] のどちらに置くかが定義に無い。
- 000050 kundo（訓導）: ゴール 秩序 +1（場面2・4）。本文は「村の学校の訓導」という職業と、常夏の名を教える口調以外に、規範を示す言動が無い。職業からの推定で、本文の言動には根拠が薄い。uba の 秩序 +1（場面0）も、丁寧な言葉遣い「御不都合な、つい話に実が入りまして」程度が根拠。
- 000081 giovanni・campanella の宿命・自由意志 +1: ゴールは場面1・2・4 で付ける。本文は「ぼくたちも降りて見ようか」「降りよう」「早くあすこへ行って見よう」、場面4 の「世界中だってかけれる」。探索の意欲を「開拓」と読めば +1 だが、軸の定義の「抗い」までは本文から読めない。

### 4.4 同席・場所・時刻
- 同席の外れ（1 件）: 000035 場面2 の tsuneko。場面末尾が「笑いながら相手の女給に、」で、次の場面の相手へつながる。ゴールは居合わせるとし、注釈は話題としての言及と判断した。
- 場所（3 件）: 000081 場面5 は、ゴール「汽車」、注釈「車室」（どちらも本文に出るが、同じ場所の別の言い方で一致規則を満たさない）。000081 場面3 はゴール「白い岩」、注釈は本文に場所名が無いとして null。000050 場面1 はゴール「お店」（本文「大層お店の邪魔をしました」）、注釈は null。
- 明示時刻（2 件）: 001383 場面1 は、ゴールが「暫くしてから」を明示時刻とし、注釈は elapsed_hint に入れた（フィールドの境界の違い）。001875 場面3 は、注釈が「きょう」を出し、ゴールは時刻なし。
- 時間順序（1 件）: 000050 場面2 は、ゴール unknown、注釈 parallel（場面が人物と場所を替えて同時期と判断）。

## 5. 切り分け

| 項目 | 強いモデルでの到達 | 判断 |
|---|---|---|
| 同席、順序、場所、明示時刻 | 0.91〜1.00 | 課題とゴールは成立。ローカルの低さはモデル側 |
| 事実 | P 0.52（補正後 0.58）／R 0.77（補正後 0.85） | R は上がる。P の上限は粒度の定義とゴールの件数で決まる。HOOK の言い換えと向きの違いは照合規則で落ちる |
| 特性 | 場面単位 48/97、人物単位 24/47、逆符号ほぼ 0 | 強いモデルでも約半数。外れは「ゴール非0・注釈 0」が中心で、軸定義の重なりと人物単位の値の付け方の違い |

- ローカルの特性の低さ（人物単位 5/47）は、強いモデルとの差が 5/47 対 24/47 あり、モデル側の影響が大きい。同時に、強いモデルでも非0軸の約半数は外れており、残りの半分は定義とゴールの問題。
- 強いモデルの逆符号が 0〜1 件（軸が合えば符号は合う）のため、特性の評価を「非0の軸に出力するか」と「軸の定義」に分けて見るのが妥当。
- 注釈者とゴール作成者が同系統のモデルであるため、ここでの一致は人手の正解との一致を保証しない。
