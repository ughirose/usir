## 死角・限界・自己監査

1. **有効寄与作品数（`K_active`）と全体作品数（`K`）のズレ**: F-18 の `K*` は Set 1（46作品中 M=22作品、L=24作品が寄与）の復元抽出に基づくため、実効的には「M/L 各帯に寄与する作品数が基準の 22→`22×(K/46)` に増える」前提で計算されている。短編中心で `[≥2,≥2]` ペアが 0 件の作品（60作品中 22作品）を追加しても検出力は上がらない点に注意が必要。
2. **青空文庫テキストの段落改行仕様**: `split_paragraphs_py` は `\n` 区切りであり、青空文庫ファイル内の改行位置（形式段落）に依存する。1文が長い文体（谷崎・森鴎外など）では500字超でも1窓 `[1,1]` となり `ac_*` に寄与しない。
3. **本ステージの範囲制限**: 本レポートは調査・設計のみであり、B-16 実装の開始、本番コード・σテーブル・Gate 3a/3b・Level 3b の変更は一切行っていない。
