## 3. 停止理由：タスク B・C の未定義事項（判断待ち）
1. **「現代文レジスター」の実データが無い。** 現代文は Tier C の R1〜R3 のみで、(a) 作家ラベルが無い、(b) 1 サンプルが 1 プロファイル（原文非保持）で場面・前後半に分割できない、(c) §1 のとおり素性が未検証。v1.1 の 15 作家と 106 作品は全て青空文庫（近代）で、R4 レジスターに当たる。新規収集は禁止のため、現代文の作家間 Split-Half は既存データだけでは定義できない。
2. **R_xx の単位が未定義。** 既存の R_xx（`experiments/usir_v5_instrument_calibration.py`）は、作品を奇数・偶数場面に分けた特徴量ごとの Pearson＋Spearman-Brown で、作品間の再現性。「作家間」をどの量（作家平均プロファイル／Δz／特徴量）・どの分割（作品・場面）で測るかが §25 に無い。
3. **異常検出器が未定義。** 「異常検出 ROC-AUC」のスコア（Scheme 3 の場面内 LOO 中心化後の距離か、既存アラート仕様か）、基準集合、偽陽性率を測る閾値の決め方が §25 に無い。
4. **摂動の対象レジスターが同じ問題を持つ。** 摂動を加える「実在テキスト」は、現状で確実に実在と言えるのは R4（青空文庫）のみ。現代文で測る場合は取得元が要る。

選択肢（Orion の判断）：
- (i) 現代文の実在テキストの取得元（例：青空文庫の戦後作品、CC ライセンス文書、官公庁文書）とダウンロードの許可を示す。許可後、A の置換→B・C をやり直す。
- (ii) B・C を R4（青空文庫・近代口語）レジスター内で実施し、「現代文」を R4 に読み替える。この場合 Gate 3a の時代オフセットの論点（現代文 vs 近代）が測定対象から外れるため、通過判定の意味が変わる。
