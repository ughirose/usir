`python scripts/detector_v3/measure.py` を再実行し、`detv3_results.json` と数値が一致した（差分は `seconds` のみ）。
- v3 フル: 合算 AUC 0.8690、FPR（OP-B）0.1023

## 1. 名称対応（指示書と v3 コードの差）
指示書の q1/q2/q3' と v3 の q1/q2/q3 は番号が異なる。以下で固定する。
| v4 | 内容 | v3 の列 | 向き（異常） |
|---|---|---|---|
| q1 | 語尾（文末3文字の多様性） | q3 | 減少 |
| q2 | 読点密度 | q1 | 減少 |
| q3' | 感覚語（改良版、成分 A・B の合成） | S2a, S2b（q2 は使わない） | A: 減少 / B: 増加 |

q1・q2 の入力値は `data/detv3_scene_signals.npz` の既存列をそのまま使う。S1・S2 は独立軸に入れない。

## 2. 入力量
- 語リスト: `P2B._SENSE`（v3 の S2 と同一の凍結閉集合。拡張しない）。「感覚語数」は v3 と同じく、地の文中の `_SENSE` に属する文字数で数える。
- 地の文: 空白類を除いた場面テキストから `「…」`・`『…』` を除去したもの。
- 新規に保存する量は **L_narr（地の文の文字数）** のみ。`scripts/detector_v4/signals.py` が v3 の `signals()` に L_narr を足した 9 列（q1,q2,q3,LS,DR,S1b,S2a,S2b,L_narr）を `data/detv4_scene_signals.npz` に出力する。既存 8 列は v3 の npz と完全一致することを生成時に検証する。

## 3. 正規化（v3 と同一）
- 信号 q1, q2, A(=S2a), B(=S2b) の各々に対し、作品内 LOO 経験ベイズ正規化（m0=8、`detector_v3.loo_normalize` と同一式）。μ_G・σ_W・校正分布は学習 fold の無摂動場面のみから求める。
- 向き sgn: q1=−1, q2=−1, A=−1, B=+1。
- 片側分位スコア: u = −log p、p = (1 + #{校正分布 ≥ z}) / (N_train + 1)（v3 と同一）。

## 4. q3' の構成
1. 成分ごとに u_A, u_B を上記の手順で得る。
2. **ランク平均**: r_A = 1 − p_A、r_B = 1 − p_B（校正分布内の経験順位）、r̄ = (r_A + r_B) / 2。学習 fold の無摂動場面の r̄ 分布 C を作り、p_c = (1 + #{C ≥ r̄}) / (N_train + 1)、u_c = −log p_c を「合成後の −log p」とする。
3. **Hurdle 重み**: 場面 i について
   - μ_LOO,i = 同一作品の基準場面（A シナリオでは他の無摂動場面）における「地の文 1,000 字あたりの感覚語数」（場面ごとの値 = S2a × 1000）の単純平均。基準場面が 0 件のとき学習 fold の全体平均を使う。
   - E_count,i = μ_LOO,i × L_narr,i / 1000。L_narr,i は評価対象のテキスト（陽性は摂動後）の地の文長。
   - w_i = 1 − exp(−E_count,i / τ)、τ = 2.0（固定）。E_count = 0 で w = 0、E_count について単調増加、上限 1。
4. q3' の最終スコア = w_i × u_c（校正後のスコアに掛ける。A・B の校正は変えない）。校正用の学習場面にも同じ重みを作品内 LOO で計算して適用し、学習 fold の集約スコア分布を作る。
5. 集約: score = max(u_q1, u_q2, u_q3')。K = 3。

## 5. 動作点 p_OP の決定規則（登録）
1. スコア: 全 56 作品の無摂動場面（1,877 場面）に対し、全作品で学習したモデルの集約スコア（作品内 LOO 正規化済み）を計算する。
2. 作品 w ごとに、w 以外の全作品の無摂動スコアの p パーセンタイル（`numpy.percentile`、線形補間）を閾値とし、FPR_w(p) = w の無摂動場面のうちスコア ≥ 閾値の割合を求める（v3 と同じく「以上」で判定する）。
3. グリッド p ∈ {80.0, 80.5, …, 97.0}。各 p で mean_w FPR_w + 1.28 × SE_w（SE_w = 作品間 SD(ddof=1) / √56）を計算する。
4. 上記が 0.10 以下となる最大の p を p_OP とする。満たす p が無ければ 80.0。決定した p_OP の数値と各 p の表は、計測前に本書 §9 に追記してコミットする。
5. **外側評価での閾値**: 各外側 fold で、学習 fold の無摂動場面の集約スコア（学習 fold で fit したモデル、作品内 LOO）の p_OP パーセンタイルを閾値とする。全 fold で p_OP は共通。ヘッドラインは §9 に登録した p_OP を使う。
6. **指示書内の矛盾の扱い**: 指示書は「対象: 全コーパス」と「保持セット（外側 fold の評価側）の情報を使わない」を併記している。全コーパスで決めたスカラー p_OP は外側評価作品の情報を含む。そこで次の併記を事前登録する。
   - ヘッドライン: 指示書どおり全コーパスで決めた p_OP（上記 1〜5）。
   - 併記（漏洩なし版）: 外側 fold ごとに、手順 1〜4 を学習 fold の作品のみで実行して p_OP,fold を決め、同 fold の閾値に使う。
   - 両者の差と、漏洩なし版の p_OP,fold を報告する。どちらを合否の根拠にするかは Orion が決める。
7. 参考値: OP-B（p=90、v3 と同じ入れ子 5 分割の内側保持陰性の 90 パーセンタイル）での FPR・TPR も併記する。

## 6. 評価プロトコル（DETV3／P-2c と同一）
作品単位 5 分割・seed 11（`workset_folds(all_works, 11)`、内側 seed = 11 + fold）、56 作品・1,877 場面、摂動 ending／comma／sensory、分割は全体／既存／新規／外部（既存で学習、新規で評価）。AUC は 3 摂動プール（陰性との比較）、95% CI は作品単位クラスタ・ブートストラップ（B=2000、seed 7）。
- ヘッドライン: シナリオ A（陽性・陰性とも基準は同一作品の無摂動な他場面）。
- 副次診断: シナリオ B'（陽性の基準は同一摂動を適用した他場面）。合否に使わない。B' では μ_LOO も摂動後の他場面から計算する。

## 7. アブレーション（報告のみ。ヘッドラインに混ぜない）
| 名称 | 内容 |
|---|---|
| i | Hurdle 重みなし（w ≡ 1） |
| ii | q3' を v3 の q2（場面全体の感覚語率、LOO 正規化、重みなし）に置換 |
| iii | τ = 1.0、τ = 4.0 |
| iv | シナリオ B' の v4 合算 AUC |
各構成にも §5 の手順を同じ規則で適用して p_OP を決め、OP-B（p=90）の値と併記する。構成選択には使わない。

## 8. 漏洩防止
v3 設計 §6 と同一。加えて、μ_LOO は評価場面自身を除いた同一作品の場面のみから計算し、評価場面のラベルは使わない。単体テストで、評価場面自身の値を変えても自身の μ_LOO が変わらないことを確認する。

## 9. 決定した p_OP（計測前に記録。`scripts/detector_v4/pop_registered.json` に全表）
§5 の手順を `scripts/detector_v4/measure.py pop` で実行した出力（無摂動スコアのみ使用。AUC・TPR は未計測）。
- ヘッドライン構成（v4）: **p_OP = 97.0**。規則「mean_w FPR + 1.28·SE ≤ 0.10 を満たす最大の p」を満たす p は 92.5〜97.0（bound_value: 92.5→0.0973、97.0→0.0388）で、最大の p がグリッド上限 97.0 になった。満たさない p は 80.0〜92.0（92.0→0.1021、90.0→0.1228）。
- アブレーション構成（i, ii, iii τ=1/4）も同規則で p_OP = 97.0。
- 所見（計測前）: 規則が「最大の p」のため、FPR 制約が単調に緩む方向ではグリッド上限に張り付く。これは規則の帰結であり、規則は変更しない（指示書の禁止事項）。上限での TPR 低下はレポートで開示する。
