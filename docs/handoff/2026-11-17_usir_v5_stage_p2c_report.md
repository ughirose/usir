### なぜ効く／効かないか
**実測**:
- 語尾単調化は文末多様性を 0.780 → 0.149 に下げる（場面間 SD の −3.49 倍）。特徴ベクトルでは ortho 次元 16 が +4.75 SD、次元 11 が +3.06 SD、kasane 次元 27 が +3.04 SD 動く。部分空間と表層のどちらでも検出できる（AUC 0.90〜0.99）。
- 読点崩壊は読点密度を場面間 SD の −1.18 倍動かすが、32D 特徴では kasane 次元 24（−1.18 SD）・31（+0.78 SD）だけが動き、ortho は 0。感覚語欠落は感覚語率を場面間 SD の −1.02 倍動かすが、32D 特徴の平均シフトは最大 0.15 SD で、部分空間スコアでは検出できない（部分空間のみ AUC 0.510）。
- 場面間の変動係数は読点密度 0.41、感覚語率 0.49、文末多様性 0.23。
- 事後・探索的確認（事前登録外、合否に使わない、`p2c_posthoc_directional.py`）: 表層スコアを「減少のみ」の片側にすると、表層のみで合算 0.795（読点 0.731、感覚語 0.677）、合成で 0.760。登録済みの両側 |z| は、増加方向の外れ値も異常と数えるため AUC を下げていた。

**推測（検証していない）**: 上記の効果量から、等分散正規近似で単一量の AUC 上限は語尾 0.993・読点 0.797・感覚語 0.765（平均 0.852）と見積もれる。この近似は無摂動分布が正規で等分散という仮定に依存する。この見積もりが正しければ、「場面単独の絶対密度」だけを見る検出器は、読点・感覚語 50% 削除に対して合格ライン 0.85 の近傍が理論上限になる。上限を超えるには、作品内の他場面を基準に使う（作品内正規化）か、より強い摂動で評価するなどの変更が必要になる。作品内正規化は今回の事前登録範囲外で、未測定。

## 5. タスク D：補助閾値 0.9 SD の再校正

- 負例 N1: v1.1 Primary 405 件の `text_before` に転記誤差級の微小編集（1〜3 文字: 削除／重複／隣接入替）を加えた合成ペア（seed 20261717）。N0（同一テキスト）は `harvest-diff` が記録を出さない（変更なしとして扱われ旗が立たない）ため、特異度の根拠にならない。実在の無推敲ペアは取得元になく、**N1 は合成であることが限界**。正例は P-1 と同じ代理ラベル（char_change_ratio ≥ 中央値、220 件）で、正解ラベルではない。
- 再現確認: 旗数は 0.9 SD で 118 件、1.0 SD で 97 件、代理感度 0.486／0.395（P-1 と一致）。

| 閾値 | 代理感度 | N1 特異度 | 非実質的推敲の旗率 |
|---|---|---|---|
| 0.80 | 0.586 | 0.978 | 0.050 |
| 0.85 | 0.550 | 0.980 | 0.050 |
| **0.90** | **0.486** | **0.983** | 0.050 |
| 0.95 | 0.436 | 0.985 | 0.046 |
| **1.00** | **0.395** | **0.988** | 0.046 |
| 1.10 | 0.332 | 0.988 | 0.046 |
| 1.25 | 0.259 | 0.990 | 0.041 |

- N1 の abs_max 分位: 中央値 0.057、p90 0.320、p95 0.481、p99 1.222、最大 2.296。特異度 0.95 を満たす閾値は 0.481、0.99 を満たす閾値は 1.222。編集字数別（1／2／3 字）の中央値は 0.019／0.079／0.097。長さ帯別の 1.0 SD での旗率は L 帯 0%、M 帯 1.2%、S 帯（30 件）6.7%。
- abs_max の AUC: 代理正例 vs N1 が 0.935、代理正例 vs 代理非実質的推敲が 0.890。
- **提案（確定は Orion）**: 登録規則（N1 特異度 ≥ 0.95 を満たし、1.0 より感度が高い）により、**0.9 SD の維持を支持**する。0.9 は N1 特異度 0.983 で、1.0 SD との差は 0.5 ポイント、感度は +0.091（代理）。ただし N1 は微小編集の合成負例で易しく、0.8〜1.25 のどの閾値でも N1 特異度が 0.978〜0.990 に収まるため、**N1 は 0.9 と 1.0 を区別できない**。N1 の結果は「0.9 が誤警報を増やすという証拠がない」までしか言えず、0.9 が最適であるとは言えない。主閾値 1.0 SD は変更していない。S 帯（短い段落）の誤警報が相対的に多い点は別途の確認が必要。
