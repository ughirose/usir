# Phase 33: Phase C（Deadzone 誘発評価・較正ステア・GRPO-LoRA）実測

- データ: `docs/handoff/v10/p33_q3_8b.json`（stdout/stderr 同名）。Qwen/Qwen3-8B bf16、A100-SXM4-40GB、`mock_used=false`。
- 実行: A100 割当は 412 で 7 回失敗し、8 回目で成功。実行時間は wall 5356 s（モデルロード 75 s を含む）。
- 評価: instruct 説明文プロンプト 12 本（箇条書き・見出し禁止、です・ます調、800 字程度）、max_new_tokens 400、T=0.8。
- Deadzone の定義（ドライバが事前に固定）:
  - 分類器: `compute_three_phase_qda_distance(domain='novel').phase_regime == Phase_I_Deadzone`
  - CV 基準: CV_L < 0.28

## 1. base は Deadzone に落ちるか

| 条件 | Deadzone(分類器) | Deadzone(CV<0.28) | 平均 CV_L | 文字 bigram 異なり率 | ref PPL |
|---|---|---|---|---|---|
| base | 7/12 (58%, Wilson95 32–81%) | 8/12 | 0.276 | 0.655 | 1.55 |

- 半数以上が Deadzone に入った。「base は Deadzone に落ちる」は成立する。ただし n=12 で、信頼区間は広い。

## 2. 較正方向 vs ノルム一致ランダム方向

- 較正: 第 23 層（36 層中）で、12 要素それぞれに独立の ridge 回帰（λ_rel 0.1、40 テキスト）をかけた。
  - R² in-sample 平均は 0.989。5-fold CV の R² 平均は 0.658（要素別 0.39〜0.81）。
  - 列ベクトル間 |cos| の最大は 0.934 で、要素間の直交性は低い。
- Δq: Critical/Void 相コーパスの平均 q と base 生成の平均 q の差を、q_std で割って単位化したもの。
- ランダム方向: 較正方向とノルムを一致させた（scale 1.60）。

| 注入 | α | 較正 Deadzone | ランダム Deadzone | 較正 退化(bigram<0.5) | ランダム 退化 | 較正 ref PPL | ランダム ref PPL |
|---|---|---|---|---|---|---|---|
| all | 0.05 | 5/12 | 8/12 | 1 | 0 | 2.04 | 1.61 |
| all | 0.15 | 8/12 | 5/12 | 12 | 3 | 1.51 | 2.19 |
| all | 0.30 | 12/12 | 8/12 | 12 | 12 | 1.22 | 1.72 |
| last | 0.05 | 5/12 | 6/12 | 0 | 0 | 1.69 | 1.57 |
| last | 0.15 | **1/12** | 10/12 | 3 | 0 | 2.70 | 1.69 |
| last | 0.30 | 7/12 | 6/12 | 12 | 0 | 1.80 | 2.19 |

**読み方**
- 「退化」は文字 bigram 異なり率 < 0.5。この閾値は結果を見た後に置いた（base の最小値は 0.55）。
- all 注入で α ≥ 0.15 にすると、同じ句を反復するループに崩れた。
  - 例:「電子レンジを安全に使うためにはまず…」を 400 トークンまで反復する。
  - この崩れは 1 文として扱われるので、低 CV で Deadzone と判定される。ref PPL が低いのは反復のためで、品質を示していない。

**結果**
- 較正方向がランダム方向より Deadzone を減らした設定は 4 つある: all/0.05、last/0.05、last/0.15、そして全件退化した all/0.30 の比較を除いたもの。
- 最も差が大きいのは last/0.15（1/12 vs 10/12）だが、代償がある:
  - 12 本中 3 本が退化した（bigram 0.17〜0.45、「〜ていて」の連鎖など）。
  - ref PPL は 2.70 で、base 1.55・ランダム 1.69 より高い。
- 「Deadzone を外れ、かつ非退化」の本数（事後指標）: base 5、較正 last/0.15 9、ランダム last/0.15 2、較正 last/0.05 7、ランダム last/0.05 6。
- 判定:
  - 較正方向がランダム方向に勝つ傾向は、last 注入の α 0.05〜0.15 に限って見られる。
  - ただし PPL 上昇と一部退化を伴う。用量反応も単調ではなく、0.30 では両方向とも崩れるか効果が消える。
  - 「較正ステアが Deadzone を解消する」とは主張できない。
- ステアのレイテンシ: base 53.41 ms/tok に対し、all/α0.15 は 54.20 ms/tok（+1.47%）。
- 健全性: フック除去後の logit 差は 0.0（除去は完全）。

## 3. GRPO-LoRA（merged）

- 構成: LoRA r=8 / α=16（72 モジュール、3,833,856 パラメータ）。
- 学習: 40 step、2 prompt × 4 rollout、256 トークン、lr 2e-4、β_KL 0.04。学習時間 1515 s、ピークメモリ 18.7 GB。
- 報酬: 乗法 GRPO 報酬（物理項）に ref PPL バリアを掛けたもの。
  - バリアは base PPL の 90 パーセンタイル（1.736）を閾値とするシグモイド。
- 学習曲線:
  - 平均報酬は先頭 10 step 平均 0.081、末尾 10 step 平均 0.077、最終 step 0.144（std 0.077）。
  - **報酬は上昇していない。** KL の最大は 0.0054。
- 評価:

| 条件 | Deadzone(分類器) | Deadzone(CV) | 平均 CV_L | bigram | ref PPL | 物理報酬(PPLなし) |
|---|---|---|---|---|---|---|
| base | 7/12 | 8/12 | 0.276 | 0.655 | 1.55 | 0.102 |
| LoRA merged | 8/12 | 8/12 | 0.264 | 0.663 | 1.55 | 0.100 |

- **merged LoRA は Deadzone を減らしていない**（7 → 8/12）。他の指標も base とほぼ同じ。
  - KL が小さいことと合わせると、40 step の学習ではモデルがほとんど動いていない。
  - merge 前後の logit 差の最大は 0.31。
- レイテンシ（64 トークン × 5 反復）:

| 状態 | ms/tok | base 比 |
|---|---|---|
| original | 54.10 | — |
| merged | 54.01 | −0.17% |
| unmerged | 66.43 | +22.8% |

- merge 後のオーバーヘッドがほぼ 0 である点は成立した。ただし、merge した重みが効果を持っていないので、価値の主張にはならない。
- merged と unmerged の logit 差の最大は 0.25（bf16 の丸め誤差の範囲）。

## 4. Phase 33 の成功基準との対応

## 5. 未検証・次手

- GRPO の step 数・lr を増やした場合と、報酬が上昇しない原因（報酬の分散が小さい、群内 advantage が小さい、など）は未検証。
- ステアの退化を検出して打ち切る仕組み（bigram ガード）がない。
- n=12、単一 seed 系列。有意性は主張しない。
