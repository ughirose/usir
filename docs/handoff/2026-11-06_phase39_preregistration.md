# Phase 39: 事前登録（文学の場面プロンプトでのステア再評価、実行前に固定）

## 目的
Phase 38-1 のプロンプト 12 本は、家電の使い方や複利の説明などの説明文の課題だった。QDA Deadzone の分類器は小説の領域（`domain="novel"`）で較正されている。ステアが文学の文章でも Deadzone を減らすかを、Phase 38-1 と同じ手順と基準で確かめる。

## 実行
- ジョブ: `p39c_q3_8b_s{1,2,3}`（`artifacts/colab_run/build_colab_p33.py`）。
- 条件は Phase 38-1 と同じ。
  - Qwen3-8B、A100、第 23 層、last 注入、単位方向、α ∈ {0.08, 0.12}。
  - max_new_tokens 1024、GRPO なし。
  - seed 20261106 / 20261206 / 20261306。
- 変更点はプロンプトだけ（`--prompt-set literary`）。
  - `run_phase33_phase_c.py` の `LITERARY_PROMPTS` を使う。
  - 12 本の場面の指示に、次の共通の指示をつける。「小説の地の文として、だ・である調で800字程度で書いてください。見出しや箇条書きは使わないでください。」
  - 作家名、作品名、人物名は含めない（テストで確認済み）。
- Δq は系列ごとに、その系列の base 生成から較正する（Phase 38-1 と同じ）。
- 集計: `scripts/phase38_steer_eval.py --prefix p39c_q3_8b --out p39_steer_eval.json`。Phase 38-1 と同じコードを使う。

## 成功基準（Phase 38-1 と同じ。すべて満たしたとき「文学の場面でもステアは Deadzone を減らす」とする）
1. 末尾の断片を除いたテキストの QDA Deadzone をプールした件数（n=36）で、較正 α 0.12 < ランダム α 0.12、かつ較正 α 0.12 < base。
2. 3 系列のうち 2 系列以上で、較正 α 0.12 < ランダム α 0.12。
3. 較正方向（α 0.08 と 0.12）の退化（文字 bigram < 0.5）が 0 件。
4. 較正 α 0.12 の ref PPL の平均が、base + 0.5 以内。

## 判定不能の規則（結果を見る前に固定）
- base の Deadzone がプールで 5/36 以下なら、減らす余地がほとんどないので、基準 1 の base との比較は「判定不能」とする。
  - この場合も、ほかの基準は判定して報告する。
