## 3. タスク3：Horizon Bias（および ISF 境界・切り詰め実験）の検証

### 3.1 コーパス基礎統計と回収ラグ分布

- 相対時間回収ラグ $\Delta u = (c_{\text{idx}} - o_{\text{idx}}) / T_W$ 分位: **`[0.0039, 0.0067, 0.0173, 0.0571, 0.1577, 0.3333, 0.9320]`**

長編では回収ラグが最大 213 場面に及ぶ一方、コーパス中央値の作品場面数は 17 場面に過ぎない。提示時点で後続場面が $R = T_W - 1 - o_{\text{idx}}$ 場面残るとき、定常ハザード率 $\lambda$ を仮定した理論モデル上は未回収確率が $(1 - \lambda)^R$ に従って減衰するため、総場面数が多い作品ほど生 `hook_survival` は機械的に低い値をとる。

### 3.3 固定場面ホライズン $H$ と4手法の挙動比較
各 $H \in \{1, 2, 3, 5, 8, 10, 15, 20, 30, 50, \infty\}$ について以下4定義を評価した（$N=106$、`uncensored` は `o_idx + H < T_W` のフックのみ持つ有効作品数 $N_{\text{valid}}$）：
1. **Simple Fixed-$H$**: $H$ 場面以内に閉じなければ一律「未解決」（末尾右打ち切りも未解決扱い）
2. **Uncensored-Only $H$**: 後続が $H$ 場面未満しかない末尾フックを分母から除外
3. **Hazard Norm ($H_{\text{ref}} = H$)**: 各フックの観測可能曝露 $e_i = \min(\text{lag}_i \text{ or } (T_W-1-o_i), H)$ を合計し $E = \sum e_i$、回収数 $C$ から $\hat{\lambda} = C / (E + 1)$、生存率 $S = (1 - \hat{\lambda})^H$
4. **Hazard Norm ($H_{\text{ref}} = 5$)**: 同上 $\hat{\lambda}$ を共通参照ホライズン $H_{\text{ref}}=5$ に変換 $S = (1 - \hat{\lambda})^5$

### 4.2 推奨案とトレードオフ

#### 第一推奨（案 A）：右打ち切り曝露正規化・離散ハザード生存率 + ISF 構造修正
$$
S_{\text{haz}}(H, H_{\text{ref}}; \tau_0) = \left(1 - \frac{C_H}{E_H + \tau_0}\right)^{H_{\text{ref}}}, \quad
E_H = \sum_{i \in \mathcal{H}} \min\bigl(\text{lag}_i \text{ or } (T_W - 1 - o_i),\; H\bigr)
$$
ここで $C_H$ はフック提示から $H$ 場面以内に回収されたフック数（重み付き版では各フックにビン重み $\omega_b$ を乗じて $C_H, E_H$ を加重和する）、$\tau_0$ はラプラス事前曝露正則化（$\text{exposure}=0$ のゼロ除算と過学習を防止）。
- **推奨パラメータ**: $H \in \{10, 15\}$（コーパス回収ラグ P75=$18$・中央値=$6$ に整合）、$H_{\text{ref}}=5$（5 場面後の残存確率として出力レンジと線形性を保つ）、$\tau_0 \in [0.5, 1.0]$（感度確認：$\tau_0 = 0.0 / 0.25 / 0.5 / 1.0 / 2.0 / 3.0$ に対し $H=10$ の $\rho$ は $-0.0750 / -0.0778 / -0.0832 / -0.0920 / -0.1128 / -0.1331$、$\eta^2_{\text{author}}$ は $0.0759 \sim 0.0787$ と滑らか）。
- **併設必須（注釈側修正）**: `aozora_scene_splitter.py` L416 の作品内 ISF をコーパス基準ストップワード辞書／固定語彙統計へ置換するか、$T_W < 10$ でも `sf >= 2` を許容する場面数保護を設ける（$T_W < 10$ の $40.4\%$ 回収不能バグを除去）。
- **利点**:
  1. **長さ独立性の直接実現**: OLS 回帰や外部コーパス統計に頼らず単一テキストだけで $\rho = -0.0920$ ($H=10$) $\sim -0.0442$ ($H=15$)、$r = -0.0072$ と無相関化。
  2. **連続性と高解像度**: 値域が `[0.031, 1.0]` に滑らかに分布しユニーク値数が `82〜84`（`Block Median W=6` の `33` に比して $2.5$ 倍の識別解像度）。
  3. **切り詰めロバスト性**: 同一長編の $K=20 \to 200$ 切り詰めに対し平均変動を約 $1/7 \sim 1/10$（$+0.360 \to +0.036$）に抑制。
- **トレードオフ**:
  1. $H=15, H_{\text{ref}}=15$ のように基準期間を長くすると $\rho = -0.0442$ ながら標準偏差が拡大（$0.269$）し $r=-0.077$ になる。$H_{\text{ref}}=5$ に固定する方が分布は安定するが、$H=15$ 時に $r=+0.061$ とごく弱い正傾きが生じる（$H=10, H_{\text{ref}}=5$ が $\rho=-0.092, r=-0.007$ でバランス最良）。
  2. 回収数 $C_H = 0$ のテキストではすべて $S_{\text{haz}} = 1.0$ になる（$16/106$ 作）。

#### 第二候補（案 B）：Tier-2 場面ブロック中央値（$W=6$, stride=$3$）
- **根拠数値**: $\rho = -0.0152$ ($p=0.88$), Pearson $r = +0.0562$, **nHSIC = $0.0155$**（非線形含め長さ独立性が全候補中最も高い）。
- **トレードオフ**: ブロック長を $W=6$ に固定するため短編およびブロック境界を跨ぐ長距離伏線（中央値ラグ $6$、P75=$18$ 場面）を切り捨て、$37/106$ 作（$34.9\%$）が $1.0$ に飽和しユニーク値も `33` 通りへ離散化する。P-3 の「連続化・精緻化」要件に対して解像度が不足するため、補助統計量またはクロスチェック用途に留めるのが妥当である。

#### 非推奨案（却下根拠）
- **5幕相対時間ホライズン・相対時間ハザード率**: Horizon Bias を温存（$\rho = -0.686 \sim -0.725$）するか逆方向に過剰補正（$+0.728$）する。
- **単純固定ホライズン $H$**: 右打ち切り未補正のため $\rho \le -0.26$（$H=5$ で $-0.371$）が残る。
- **Uncensored-Only $H$**: 短編と末尾フックが大量脱落し全作品評価が破綻する。
- **コーパス OLS 回帰残差化の単独運用**: 線形平均だけを引き剥がし、短編の物理バイアス（`1.0` 張り付き・ISF破綻）と非線形依存（nHSIC $0.061$）を隠蔽したまま外部学習パラメータへ依存させる。P-3 ではまず案 A で生特徴量自体の長さバイアスを除去した上で、残差化の要否（THRESHOLD `0.20` に該当しないため自動スキップ可）を判断すべきである。

## 5. 自己内省・冷徹な客観監査（Ruthless Self-Critical Audit）

1. **誤爆・過学習・生態学的交絡の限界（False Positive Risk）**:
   - **作家スタイルと作品長の交絡**: 生指標における10著者間の効果量 $\eta^2 = 0.1539$（ANOVA $p=0.055$, Kruskal-Wallis $p=0.049$）は、案 A（$H=10$）で $\eta^2 = 0.0763$（$p=0.545$）、現行 Python OLS 残差化でも $\eta^2 = 0.0680$（$p=0.637$）へ低下する。たとえば $T_W \ge 200$ の長編7作品は夏目4・泉1・谷崎1・坂口1が占める一方、F6 で唯一64文未満だったのは梶井基次郎「桜の樹の下には」（3場面、`hook_survival=1.0`）であり、生値で見えていた著者平均差（宮沢 $0.8440$・梶井 $0.7972$ vs 夏目 $0.5401$・谷崎 $0.5966$）の相当部分が「作品長の偏り $\times$ Horizon Bias」と交絡していた可能性が示唆される。ただし、短い作品に特有の未解決志向と長さの機械的効果を作者別に完全分離するには、同一作家の短編・長編対比による統制検証が別途必要となる。
   - **長編における $H \to \infty$ のわずかな正傾き**: ハザード窓を無制限（$H=\infty$）にすると $\rho = +0.1425, r = +0.2492$ へ傾く（不均一ハザードへの定常指数モデルの当てはめ誤爆）。窓上限 $H=10 \sim 15$ の維持が必須である。
2. **取りこぼし・未検証範囲（False Negative & Coverage Gaps）**:
   - **1場面短編 / D10 連続化領域の境界縮退**: 場面分割数 $T_W = 1$ の超短文・単一場面入力ではすべてのフックが $T_W - 1 - o_{\text{idx}} = 0$（閉鎖機会ゼロ・曝露 $E_H = 0$）となり、案 A でも一律事前値 $(1 - 0)^5 = 1.0$ へ退化する。P-3 で D10 連続化（数文〜数段落スケール）を扱う場合は、場面インデックス差 $c_{\text{idx}} - o_{\text{idx}}$ ではなく**文インデックス差または文字距離ベースの曝露 $E$** へ拡張しない限り、短い入力側での不連続・定数張り付きを取りこぼす。
   - **`hook_survival_idf` ハザード版の未別途集計**: Task 3・4 のハザード比較および切り詰め集計（`b20_kamae_results.json`）は無重み `hook_survival` で実測しており、IDF 加重ハザード版（`ω_b` 加重）の数値表は別途生成していない。現状 $\omega_b \in [1.058, 1.140]$ のため挙動はほぼ同等と推論されるが、未実測であることを明記する。
   - **フック抽出器自体の言語的妥当性**: `RE_HOOK_TRIG`（23パターン）と `RE_RESOLV_MARKER`（13パターン）＋漢字トークン部分文字列一致によるヒント・回収ラベルの誤検出率・取りこぼし率は本ステージのスコープ外であり未評価である。
3. **仮説と実測データの乖離**:
   - 当初「Rust と Python の定義差（窓・IDF等）」を疑った仮説に反し、生計算は 100% 同一であり、差の 100% 超が OLS 残差化のみに起因していた。
   - また「5幕相対時間による正規化が Horizon Bias を解消する」という仮説は実測により完全に棄却された（$\Delta u \le \tau$ は $\rho \approx -0.70$ を維持、$k_{\text{rel}}$ は $\rho = +0.728$ へ反転）。
