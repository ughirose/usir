## 4. タスク C'：摂動 ROC-AUC・偽陽性率
実装 `scripts/p2b/p2b_analysis.py`。事前登録のパラメータどおり（語尾単調化 100%、読点削除 50%、感覚語削除 50%。感覚語の語彙は `PHYSICAL_SENSE_INTERVALS` の 201 字）。摂動で 809 場面のほぼ全てのテキストと特徴が変化したことを確認した（v2 コーパスでの点検。v3 では未再点検）。検出器は Scheme 3 空間の標準化距離（L2）、動作点は無摂動スコアの 90 パーセンタイル（7.22）。

| 摂動 | AUC（in-sample） | 95% CI（作品クラスタ B=2,000） | 動作点での検出率 |
|---|---|---|---|
| 語尾単調化（100%） | 0.910 | 0.871〜0.944 | 66.4% |
| 読点崩壊（50%） | 0.530 | 0.503〜0.557 | 10.8% |
| 感覚語欠落（50%） | 0.510 | 0.506〜0.516 | 10.3% |
| **合算（3 種）** | **0.650** | **0.631〜0.671** | 29.1% |

- 偽陽性率: in-sample 10.01%（動作点が無摂動の 90 パーセンタイルのため構成上ほぼ 10%。循環で、検出力の証拠にならない）。
- 保持評価（副解析、作品単位 5 分割交差適合、保持作品のみ）: 偽陽性率 19.7%（分割ごと 4.1%〜38.3%）、合算 AUC 0.634（CI 0.599〜0.668）、語尾 0.870・読点 0.523・感覚語 0.508。
- 用量反応（副、合否に使わない）: 語尾 50% で 0.649、読点 25% で 0.504、読点 100% で 0.712、感覚語 25% で 0.505、感覚語 100% で 0.525。
- **合格ライン（§25、AUC ≥ 0.85 かつ FPR ≤ 10%）に対する照合**: 合算 AUC 0.650 は下回る。語尾単調化のみ 0.85 を超える。保持評価の偽陽性率 19.7% も 10% を超える。in-sample の 10.01% は、ラインを機械的に比べれば 0.01 ポイント超過で、循環のため判定材料にならない。事前登録どおり見出し値は 3 種合算。
- 読点崩壊・感覚語欠落の AUC が低い理由は検証していない。特徴は ortho24＋kasane8 の 32 次元で、読点以外の次元が摂動で動くため特徴は変化するが、場面間のばらつきの中で埋もれている（推測）。
