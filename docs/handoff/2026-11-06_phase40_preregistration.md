# Phase 40: 事前登録（文学の場面プロンプトで、文長の変動係数 CV_L を主指標にしたステアの検証）

## 背景
- Phase 39 では、文学の場面プロンプトで全条件の Deadzone が 0/36 になり、Deadzone の件数では効果を測れなかった。
- 同じデータを結果を見たあとに CV_L で集計したところ（探索、`docs/handoff/v10/p39_cv_exploratory.json`）、次の値だった。
  - 較正 α 0.12 − base: 平均 +0.023（36 対中 19 対で正、Wilcoxon 片側 p = 0.083）。
  - 較正 α 0.12 − ランダム α 0.12: 平均 +0.014（36 対中 25 対で正、p = 0.072）。
- この差が再現するかを、新しい seed で確かめる。Phase 39 のデータは判定に使わない。

## 実行
- ジョブ: `p40c_q3_8b_s{1,2,3,4}`。
- seed: 20261406 / 20261506 / 20261606 / 20261706（Phase 38・39 とは重ならない）。
- プロンプト: Phase 39 の文学の場面 12 本（`--prompt-set literary`）。
- α ∈ {0.12, 0.16}。0.12 を主とし、0.16 は報告のみ。
- そのほかは Phase 39 と同じ。Qwen3-8B、第 23 層、last 注入、単位方向、max_new_tokens 1024、GRPO なし。
- 集計: `scripts/phase40_cv_eval.py --prefix p40c_q3_8b --series s1 s2 s3 s4 --alphas 0.12 0.16`。

## 主指標
- 各出力の CV_L（抽出器の `len_cv`）。最後の文末より後ろの断片を除いたテキスト（`strip_incomplete_tail`）で計算する。
- 同じプロンプトと seed の対で比べ、4 系列をプールする（n = 48 対）。
- Deadzone は CV_L が低い側にあり、ステアの目標（コーパスの II・III 相の平均）は CV_L が高い側にある。そのため、効果は CV_L の上昇として現れると予想する。

## 成功基準（すべて満たしたとき「文学の場面で、較正ステアは文長の変動を大きくする」とする）
1. 較正 α 0.12 − base の平均が正で、Wilcoxon 符号順位検定（片側）の p < 0.05。
2. 較正 α 0.12 − ランダム α 0.12 の平均が正で、同じ検定の p < 0.05。
3. 4 系列のうち 3 系列以上で、較正 α 0.12 の CV_L 平均 > ランダム α 0.12 の CV_L 平均。
4. 較正方向（α 0.12 と 0.16）の退化（文字 bigram < 0.5）が 0 件。
5. 較正 α 0.12 の ref PPL の平均が base + 0.5 以内。

## 報告のみ
- α 0.16 の結果。
- 中央値、正の対の数、途中切れの件数。
- QDA Deadzone の件数。
- 多重比較の補正はしない。主たる判定は、基準 1 と 2 の両方が p < 0.05 であることとする。

  2. 較正 α 0.12 − ランダム α 0.12: +0.0004、正の対 23/48、p = 0.57。**未達**。
  3. 系列別の較正 − ランダムは s1 +0.003、s2 −0.028、s3 −0.021、s4 +0.047。2/4 系列で、**未達**（3 系列以上が必要）。
  4. 退化 0。**達成**。
  5. ref PPL 2.056 ≤ 2.461。**達成**。
- 総合: **未達**。Phase 39 の探索で見えた較正とランダムの差（+0.014）は、新しい seed では再現しなかった（+0.0004）。
- α 0.16（報告のみ）: 較正 − base +0.034（p = 0.030）、較正 − ランダム +0.025（p = 0.14）。
- 解釈:
  - 文学の場面では、どちらの方向にステアしても、base より CV_L がわずかに上がる。
  - 較正方向に固有の効果は、α 0.12 では見えなかった。
  - α 0.16 の値は事前に主指標と定めておらず、多重比較の補正もしていないので、根拠にしない。
