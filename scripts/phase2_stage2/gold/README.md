# Stage B ゴールド

- 作成: セッションのモデル（Claude）が、nishiki segment で分割した場面本文を直接読んで作成。作成時点でセンサー（qwen2.5:14b）の scene 注釈出力は開いていない（出力件数ログのみ参照）。このファイルのコミット時刻がセンサー出力のコミットより前であることで確認できる。
- 限界: 作成者は1名（モデル）。人手の二重注釈・評価者間一致は無い。価値観・事実更新は主観を含み、値は確定的な正解ではなく「1人の読み手の判断」である。
- 規約:
  - present: 場面内でその場に居る名簿人物（話者・動作主体・語り手を含む。話題・回想・伝聞のみの人物は含めない）。
  - relative_order: 作品の先頭場面は unknown。他は本文から continuous / flashback / parallel / unknown。
  - explicit_time: 本文中の時間表現の許容表層リスト（空＝時間表現なし）。location_surfaces: 場所を指す本文中の許容表層リスト（空＝場所の明記なし）。
  - states: 能動的な人物のみ。6軸は生死・秩序・世俗/神秘・利己/献身・理性/情念・宿命/自由意志、値 {-1,0,+1}、本文で裏付けられない軸は 0。
  - facts: 場面内で起きた事実更新（7述語）。subject は名簿 id または null。object は短い語句。
